Référence de la classe Chips

Ce composant reproduit un MaterialDesign::Chip en se basant sur un Qt Rectangle. A noter que l'ombre doit être définie avant le rectangle, de façon à être dessinbée avant, donc dessous. A noter que le Rectangle contient un texte, mais ne s'adapte pas automatiquement à la longueur du texte. C'est plutot le texte qui s'adapte au rectangle parent. Plus de détails...

Description détaillée

Ce composant reproduit un MaterialDesign::Chip en se basant sur un Qt Rectangle. A noter que l'ombre doit être définie avant le rectangle, de façon à être dessinbée avant, donc dessous. A noter que le Rectangle contient un texte, mais ne s'adapte pas automatiquement à la longueur du texte. C'est plutot le texte qui s'adapte au rectangle parent.

Voir également
{https://doc.qt.io/qt-5/qml-qtquick-controls2-label.html}
