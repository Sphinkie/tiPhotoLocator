Référence de la classe GlobalTag

Composant représentant une ligne complète dans la zone GlobalTags : un Chip (valeur du tag) + bouton "Apply to all" + bouton "Apply to selection" + description. Plus de détails...

Graphe d'héritage de GlobalTag:

Signaux

void applyAll ()
 Emis quand l'utilisateur clique sur "Apply to all".
void applyToSelection ()
 Emis quand l'utilisateur clique sur "Apply to selection".

Propriétés

string tagName
 Préfixe affiché dans le Chip (ex: "artist:", "city:").
string content
 Valeur courante du tag.
string tagDescription
 Texte explicatif affiché à droite.
bool applied
 Si true, "Apply to all" est désactivé (car déjà appliqué).
int selectionCount
 Nombre de photos sélectionnées (pour activer "Apply to selection").
string chipCategory
 Catégorie de couleur du chip.
