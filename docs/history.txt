 TiPhotoLocator — Historique des versions

--------------------------------------------------------------------------------
 Version 2.0  (2026-06-19)
--------------------------------------------------------------------------------

Reconnaissance de lieux par IA
  - Nouvelle classe C++ LandmarkWrapper : appel REST vers Groq API (Llama-4 Scout 17B), image envoyée en base64
  - Signaux : landmarkFound(name, lat, lon), locationUnknown(), networkError()
  - Bouton "Ask AI" dans la toolbar Carte (ToolbarMap.qml)
    Si lieu identifié → chip "location" affiché + SavedPosition renseignée
  - IA choisie = Groq (API OpenAI-compatible, plus rapide, HuggingFace étant payant pour cette fonctionalité)
  - Groq ajouté aux crédits (AboutDialog)
  - Qt6::Network ajouté dans CMakeLists.txt

Robustesse & Gestion des erreurs
  - ExifWriteTask : en cas d'échec, la photo reste marquée "à sauvegarder" et un snackbar d'erreur s'affiche
  - Photo.h : champ writeError (QString) pour mémoriser le message d'erreur ExifTool
  - Snackbar.qml : nouveau composant (bas-gauche, parent: Overlay.overlay, 5s auto-fermeture, fondu)
  - Warning avant fermeture si des modifications ne sont pas sauvegardées (QuitWarningDialog.qml)

Zone Suggestions
  - ZoneSuggestedLocations : bouton "Clear" => SuggestionModel.clearByCategory("geo")
  - nouvelle méthode C++ : SuggestionModel::clearByCategory(category) — suppression à rebours avec beginRemoveRows/endRemoveRows

Interface
  - Chip City affiché dans l'onglet Preview (première page)
  - Tooltips : conversion du ToolTip "attaché" vers "composant" ToolTip inline pour pouvoir ajuster sa position en y.

Corrections de bugs
  - Chips : touche Suppr avec inputMask — event.accepted=false pour laisser TextInput C++ agir (sinon le curseur n'avançait pas après effacement)
  - applyCreatorToSelection : slot C++ + signal QML + connexion main.cpp manquants (la méthode était appelée depuis QML mais non implémentée)

Qualité & Nettoyage
  - Cleanup qmldir

 Version 1.8  (2026-06-02)
--------------------------------------------------------------------------------

Interface & Animations
  - Animation de suppression sur les Chips : fondu + rétrécissement (opacity 1→0, scale 1→0.6, 250ms EaseOutQuad)
  - Mécanisme : état QML "deleting" + Transition ; signal deleteClicked émis après l'animation
  - Chips Latitude et Longitude animés simultanément lors d'une suppression GPS
  - Bouton "Clear GPS coords" déclenche aussi l'animation sur les deux chips

Zone "Global Tags"
  - Nouveau composant GlobalTag : encapsule une ligne complète (chip + boutons + libellé)
  - Bouton "Apply to selection" ajouté à côté de "Apply to all" sur chaque tag
  - "Apply to selection" activé uniquement si ≥ 2 photos sont sélectionnées (_photoModel.selectionCount)
  - ZoneGlobalTagsForm refactorisée : GridLayout remplacé par ColumnLayout de GlobalTag
  - Fix : bouton "Apply to selection" se grise après clic (flag xxxApplied manquant)

Zone "Keywords"
  - Bouton "Assign to selection" ajouté dans KeywordsRepeater
  - Nouvelle méthode C++ addKeywordToSelection() — n'ajoute que si non présent
  - addKeywordToAll() : un seul signal dataChanged émis en fin de boucle (au lieu de N)

Zone "Suggestions"
  - Scission en deux panneaux : 2/3 gauche (tous tags sauf keywords) + 1/3 droit (keywords uniquement)
  - SuggestionRepeater : propriété onlyKeywords (false par défaut) — filtre l'affichage par type
  - ZoneSuggestedTagsForm : alias onlyKeywords exposé vers l'extérieur
  - TabFramePhotoTags : RowLayout remplace le ZoneSuggestedTags unique
  - Animation de translation lors du clic sur un Chip suggestion : le chip "vole" vers le centre de sa zone destination (Option A — coordonnées dynamiques)
  - GhostChip.qml : rectangle animé créé dans ghostLayer (z:999), déplacement + fondu + réduction (300ms InOutCubic)
  - La mise à jour du modèle (setPhotoProperty + removePhotoFromSuggestion) est déclenchée en fin d'animation
  - ghostLayer : Item transparent ancré à la fenêtre (Main.qml), sert de conteneur pour les ghost chips
  - getCenterForTarget : fonction passée de TabFramePhotoTags/TabFramePhotoMap → ZoneSuggestedTags → SuggestionRepeater, calcule via mapToItem() le centre de la zone destination selon le target du chip
  - Mapping target → zone : city/country/location/lat/long → ZoneGeoloc ; keywords → ZoneUserdata ; make/model → ZoneCamera ; autres → ZonePhoto
  - Onglet MAP : les suggestions ciblent le bas de ZoneGeoloc (hauteur × 0.75)
  - Fallback si getCenterForTarget absent : animation 150px vers le haut

Aide & Tutorial
  - Nouveau popup tutoriel : 4 pages (image + texte + dots de navigation animés)
  - Popup sans frame Qt native (background: Item {}) — carte dark semi-transparente flottante
  - Ouverture automatique au premier lancement ; flag persisté dans les QSettings (groupe "tutorial")
  - Accessible à tout moment via Help → Tutorial
  - Images dédiées dans Resources/Tutorial/ (bellaminette-xxx.png)
  - Indication des bellaminettes originales ou modifiées par IA
  - Ajout du dessinateur B. Bellamy dans les crédits
  

Qualité & Nettoyage
  - Renommage updatePhotoKeyword → replaceKeywordForCurrent (cohérence avec replaceKeywordForSelection)
  - findInCirclePhotos() : court-circuit si photo sans GPS (resetCircle) ou si centre+rayon inchangés

Corrections de bugs
  - Suppression Lat ou Long : les deux coordonnées sont effacées (et non une seule à zéro)
  - Ctrl+clic : le curseur visuel (highlight) de la ListView reste sur la photo courante
  - Dialogue "Ouvrir" : s'ouvre désormais sur le dossier parent du dossier courant
  - Cercle : remise à zéro du rayon efface aussi la sélection des photos (sauf photo courante)
  - Cercle : bug de sélection parasite corrigé (cos() appelé avec degrés au lieu de radians)
  - Cercle : ouverture d'un nouveau dossier réinitialise le rayon et la sélection

 Version 1.7  (2026-05-26)
--------------------------------------------------------------------------------

Compatibilité chemins réseau
  - Support des chemins UNC (\\nas\share\...) en plus des lecteurs mappés (P:\...)
  - Normalisation automatique de l'URL du dossier (file:////serveur/... pour FolderListModel)
  - Fallback PhotoModel.scanFolder() via QDir quand FolderListModel ne supporte pas le chemin
  - ExifTool : conversion QUrl::toLocalFile() + QDir::toNativeSeparators() pour chemins locaux et UNC
  - Affichage correct du chemin UNC dans la toolbar (via window.currentFolderUrl)

Interface & Carte
  - Image de bienvenue affichée au démarrage (zone preview vide)
  - Croix rouge fixe au centre de la carte (repère visuel)
  - Focus forcé sur la première photo après chargement ou rescan d'un dossier
  - Carte centrée sur la ville d'accueil configurée dès le démarrage (correction regression)

Corrections de bugs
  - Imagettes : clip:true sur ImagettesListView pour éviter le débordement lors du scroll horizontal
  - Dossiers récents : menu "Recents" non mis à jour après "Clear" puis "Open"
  - Dossiers récents : menu "Recents" restait enabled après "Clear"
  - Sélection multiple : Ctrl+clic au lieu du clic droit (convention standard)
  - Support des caractères accentués dans les metadata EXIF/IPTC (fichier args UTF-8 + -charset IPTC=UTF8)
  - hasGPS : présence simultanée de latitude ET longitude requise
  - Effacement des coordonnées GPS corrigé
  - Certaines suggestions avaient disparu après refactoring

Qualité & Nettoyage
  - Migration toolchain MSVC → LLVM-MinGW (portabilité multi-PC)
  - Suppression du champ isWelcome (détection état vide via _photoModel.count)
  - Suppression de checkBoxExif (setting preserveExif inutilisé)
  - Écriture EXIF sélective : seuls les tags modifiés sont transmis à ExifTool (dirtyFields)
  - Correction : BusyIndicator bloqué indéfiniment après lecture des métadonnées
  - Refactoring GPS : signal centerMap passe QGeoCoordinate, homeCoords en double/double
  - PhotoModel::get() retourne des QVariants bien typés (élimine les erreurs QML "undefined")
  - Passage de Qt5Compat à QtQuick.Effects
  - Fichiers EnableDebugMode.reg / DisableDebugMode.reg pour activer le mode debug sans recompiler
